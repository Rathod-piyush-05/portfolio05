# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website! This project represents my skills, creativity, and passion for web development. It is designed to introduce who I am, showcase my projects, highlight my technical skills, and provide an easy way to contact me.

**Live Website:** https://portfolio0512.netlify.app

# 📌 About the Project

This is a responsive personal portfolio website developed to present my profile as a web developer. The website has a clean, modern design with smooth animations and an easy-to-use interface.

The main goal of this project is to demonstrate my front-end development skills while creating a professional online presence.
